### 🚀 Top Hardware & VLSI Projects

#### 💻 [8-bit Pipelined CPU in Verilog](https://github.com/Bhavin-umatiya/8_bit_cpu_Implementation)
Designed a complete 8-bit processor from scratch with a 5-stage pipeline (Fetch, Decode, Execute, Memory, Write-Back), custom ALU, and hazard detection. Functionally verified across 50+ test vectors.

#### ⚡ [64-bit Carry Save Adder on Intel DE2 FPGA](https://github.com/Bhavin-umatiya/Carry-save-FPGA)
High-performance arithmetic unit designed in RTL, verified in ModelSim, and hardware-validated on a Cyclone II FPGA achieving timing closure in Quartus Prime.

#### 🔒 [Secure Firmware Bootloader (STM32F4)](https://github.com/Bhavin-umatiya/secure-firmware-bootloader-STM32)
Bare-metal embedded C bootloader featuring checksum-based integrity validation and dual-bank flash architecture to prevent corrupted firmware execution.

#### 🧠 Neuromorphic Computing Architecture (In Progress)
Designing a brain-inspired Spiking Neural Network (SNN) accelerator with Leaky Integrate-and-Fire (LIF) neurons in SystemVerilog targeting Xilinx FPGAs.
